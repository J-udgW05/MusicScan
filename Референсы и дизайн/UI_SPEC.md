# MusicScan — UI-спецификация (референс для реализации)

Визуальный источник истины: `MusicScan.dc.html` (главное окно, окно настроек, диалоги) и `Icons.dc.html` (иконки). Ниже — значения, которые нужно перенести в код 1:1.
Ориентир платформы: Windows 11, Fluent, язык интерфейса — русский. Приложение офлайн, портативное.

Правило доступности: **статус никогда не передаётся только цветом**. Всегда пара «значок + слово»: `✓ В порядке`, `✕ Повреждён`, `! Предупреждение`, `– Пропущен`.

## 2. Тема

Три состояния настройки: `Как в системе` (по умолчанию), `Светлая`, `Тёмная`. При «как в системе» слушать смену системной темы и переключаться без перезапуска. Выбор хранится в конфиге.

## 3. Типографика

- Интерфейс: `Segoe UI Variable Text` → `Segoe UI` → системный sans-serif.
- Пути к файлам, логи, hex — моноширинный (`JetBrains Mono` / `Cascadia Mono` / `Consolas`).
- Размеры: заголовок окна 12.5px; вкладки 13.5px / 600; заголовок карточки 13px / 650; основной текст 13px; вторичный 12.5px; подписи 11.5px; моно-пути 11px; крупные числа отчёта 30px / 650 с `letter-spacing:-.02em`.
- Надзаголовки секций: 11.5px, 650, `text-transform:uppercase`, `letter-spacing:.08em`, цвет `--fg3`.
- Числа — табличные цифры (`font-variant-numeric: tabular-nums`), разряды через неразрывный пробел: `12 480`.

## 4. Геометрия

- Радиусы: окно 12, карточка 10, кнопка/поле 6, мелкий чип 5, pill-фильтр 999.
- Границы всегда 1px.
- Заголовок окна 44px; кнопки окна 46×44, закрытие на hover `#c42b2f` + белый значок.
- Отступы: контент вкладки 22px; внутри карточки 16–18px; строка списка 11px/16–18px; gap сетки 14–20px.
- Прогресс-бар: высота 6px, радиус 999, трек `--bd2`, заполнение `--acc`.
- Тумблер: 38×20, радиус 999, ползунок 14×14 с отступом 3px. Вкл — `--acc` + белый ползунок; выкл — `--bd` + ползунок `--fg3`.
- Сетка таблицы результатов: `26px 2.2fr 3fr 76px 84px 150px`, gap 12px. Размер выровнен вправо.
- Сетка строки лога: `88px 62px 1fr` (время / уровень / сообщение), line-height 1.6.
- Основная рабочая ширина окна в макете 1240px; правая колонка вкладки «Проверка» — 300px, боковая колонка отчёта — 340px.

## 5. Структура окна

Заголовок → панель инструментов → вкладки → контент → статусная строка (всегда видна).

Панель инструментов: `Выбрать папку` (акцентная, единственная filled-кнопка), `Настройки`, `Экспорт отчёта`, справа — `Справка`, `О программе` (без рамки).

Статусная строка: индикатор состояния + «офлайн», счётчик файлов, текущая папка, справа — «Портативная сборка · v1.0».

## 6. Вкладки

**Проверка.** Поле пути + `Обзор…` + зона drag-and-drop (пунктир 1.5px). После выбора папки — акцентный баннер «Найдено N подходящих файлов» с кнопками `Начать` / `Настройки` (старт не нужно искать). Далее блок хода проверки: прогресс, «X из Y · осталось ≈ N мин», текущий файл моно-шрифтом, `Пауза` / `Остановить`, справа число потоков. Ниже — живой список предупреждений со ссылкой-действием. Правая колонка: сводка счётчиков, быстрые параметры, карточка вопроса о занятом файле.

**Занятый файл** — модальный по смыслу, но не блокирующий очередь: вопросы задаются по одному, показывается остаток очереди. Варианты: `Пропустить файл`, `Подождать и повторить`, `Проверить временную копию` (+ в настройках — `закрыть владельца`). Если владелец не определён, так и написать.

**Результаты.** Поиск, pill-фильтры со счётчиками по статусам, фильтр формата, таблица, панель подробностей выбранного файла (человеческая формулировка + техническая причина) и сводка по плейлистам (найдено / битых ссылок).

**Отчёт.** 4 KPI-карточки, полоса распределения по статусам с легендой, список проверенных папок (путь / файлов / повреждено), выбор формата экспорта: HTML (с той же маркировкой), CSV, текстовый список.

**Логи.** Фильтр уровня, автопрокрутка, `Копировать`, `Очистить`. Уровни: `INFO` — `--acc`, `WARN` — `--warn`, `ERROR` — `--err`, `DEBUG` — `--fg3`.

**Настройки.** Внешний вид (тема, цвета статусов) · Форматы (чипы расширений + экспериментальный ISO/SACD, по умолчанию выкл) · Проверка (рекурсия, метаданные, порог большого файла, таймаут, параллельность, поведение с занятыми файлами, предупреждения, автопредложение старта, папка отчётов) · `Сбросить всё` — контурная, цвет `--err`.

## 7. Значения по умолчанию

Рекурсия — вкл · проверка метаданных — выкл (нет тегов ≠ повреждение) · порог большого файла — 500 МБ (100 МБ / 500 МБ / 1 ГБ / 2 ГБ / 5 ГБ / без ограничений) · таймаут файла — 60 с (дальше «подозрительный») · параллельность — авто по ядрам, максимум 8 · занятые файлы — «Спрашивать» · предупреждать о больших файлах — вкл · предлагать старт после выбора папки — вкл.

## 8. Форматы

WAV, AIFF, FLAC, ALAC, M4A, APE, WV, MP3, AAC, OGG, OPUS, WMA, MIDI, MOD, XM, IT, S3M, DSF, DFF + плейлисты M3U, M3U8, PLS, CUE. ISO (SACD) — отдельным экспериментальным переключателем.

## 9. Тон текстов

Сначала человеческая формулировка, техническая причина — второй строкой или в подробностях. Никакого «Error 0x…» в основном тексте. Числа с разрядами, время как `18:42`, размеры с запятой (`24,1 МБ`).

## 10. Иконки

Источник разметки — `Icons.dc.html`. Свои иконки не рисуются «по мотивам»: берётся файл как есть.

- Единый `viewBox="0 0 20 20"`, живая область 17×17 (отступ 1,5), координаты кратны 0,25.
- Только обводка `stroke="currentColor"`, `fill="none"`, круглые концы и стыки. Цвет наследуется от текста рядом — цветных версий иконок нет.
- Вес линии по размеру: 16 px → 1,6 · 20 px → 1,6 · 24 px → 1,5 · 32 px → 1,4.
- Размеры по месту: 16 в строках и кнопках панели, 20 в панелях, 24 в диалогах, 32 в пустых состояниях. Мельче 16 и тоньше 1,4 — нельзя.
- Заливка допускается только у `play`, `pause`, `stop`.
- Одна иконка — один смысл; повторное использование под другое действие запрещено.
- Отступ иконки от текста в кнопке 7–8 px, `flex:none`, выравнивание по центру строки (`align-items:center`).

Состав набора: folder · settings · export · help · info · search · waveform (знак приложения) · drop-zone · menu · filter · copy · clear · scan · table · report · logs · tune · stats · play · pause · stop · retry · clock · current · status-ok · status-broken · status-warning · status-skipped · audio-file · playlist · disc-image · tags · drive · busy-file · chevron-down · sort · open-external · theme-light · theme-dark · theme-system.

Статусные значки в строках таблицы рисуются одним контуром 14 px, вес 1,8, внутри цветного квадрата 20×20 с радиусом 5.

## 12. Выравнивание

- Значения-пилюли в настройках имеют `min-width:104px` и центрируют содержимое — правый край колонки выровнен по всем строкам раздела.
- Шеврон `chevron-down` 12 px, `opacity .6` — только у настоящих выпадающих списков; у переключателей и кнопок-действий его нет.
- Таблица результатов: `24px 2.15fr 3fr 72px 92px 148px`, gap 14. Размер по правому краю, статус по левому.
- Строка лога: `82px 58px 1fr`, gap 14, время моношрифтом с tabular-nums.
- Диалоги: подвал единый — второстепенные кнопки слева, основное действие справа, gap 10, фон `--mica`, верхняя граница `--bd`.
- Иконка и текст в строке всегда по вертикальному центру; иконка не участвует в переносе (`flex:none`).
