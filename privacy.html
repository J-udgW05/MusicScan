О чём эта страница

Это страница проекта Music Scan Integrity — программы для проверки музыкальной коллекции на повреждённые файлы. Здесь нет ни регистрации, ни личного кабинета, ни форм обратной связи: весь сайт — это страница с описанием и ссылками на загрузку, страница о поддержке проекта и эта страница.

Ниже перечислено ровно то, что происходит при открытии страницы. Список составлен по исходному коду сайта, который открыт и доступен для проверки.

Что сохраняется в вашем браузере

Сайт сохраняет два значения в локальном хранилище браузера (localStorage):

  • msi-theme — выбранная вами тема: светлая или тёмная
  • msi-lang — выбранный язык страницы: русский или английский

Эти записи нужны только для того, чтобы при следующем заходе страница открылась в том же виде. Они хранятся в вашем браузере и никуда не отправляются — ни на сервер сайта, ни автору, ни кому-либо ещё. Удалить их можно в настройках браузера вместе с данными сайта; страница после этого снова возьмёт тему и язык из настроек системы и браузера.

Файлы cookie сайт не использует.

Какие запросы уходят при открытии страницы

Сайт обращается к трём внешним адресам. При любом таком обращении браузер по устройству сети сообщает получателю IP-адрес, тип браузера и время запроса — это неизбежная часть работы интернета, а не сбор данных сайтом.

  • GitHub Pages — здесь сайт размещён, оттуда браузер получает саму страницу
  • Google Fonts (fonts.googleapis.com, fonts.gstatic.com) — оттуда загружаются шрифты страницы
  • api.github.com — один запрос за номером последней версии программы и именами файлов, чтобы кнопки «Скачать» вели прямо на них; уходит только с главной страницы

Обработка данных на стороне GitHub и Google подчиняется их собственным условиям: заявление GitHub о конфиденциальности и политика конфиденциальности Google. Автор сайта доступа к этим данным не имеет.

Чего сайт не делает

  • Не устанавливает счётчики посещаемости и системы аналитики
  • Не показывает рекламу и не подключает рекламные сети
  • Не собирает имена, адреса электронной почты и другие личные сведения
  • Не отслеживает вас между сайтами и не составляет профиль посетителя
  • Не передаёт и не продаёт данные третьим лицам — передавать нечего

Сама программа

Music Scan Integrity работает без подключения к сети и только читает файлы: ничего не удаляет, не переименовывает и никуда не отправляет. Настройки и база отпечатков для слежения за порчей остаются на вашем компьютере — рядом с программой либо в профиле пользователя, если рядом с программой писать нельзя.

Проверить это можно по исходному коду: репозиторий проекта открыт.

Переходы на другие сайты

Ссылки со страницы ведут на GitHub — к исходному коду, документации и файлам выпусков. После перехода действуют правила того сайта, на который вы попали.

Ваши права

Сайт не хранит о вас никаких сведений на своей стороне, поэтому запрашивать, исправлять или удалять здесь нечего. Всё, что сайт создал, лежит в вашем браузере, и вы удаляете это сами, очистив данные сайта.

По данным, которые получают GitHub и Google как владельцы серверов, обращаться следует к ним — порядок описан в их документах, ссылки выше.

Изменения

Если состав запросов или сохраняемых значений изменится, изменится и эта страница, а дата вверху обновится. История правок видна в репозитории проекта — задним числом переписать её незаметно не получится.
